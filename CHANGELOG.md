# История изменений

## 0.1.0

Первый выпуск.

- Поиск устройств в локальной сети, сопряжение по коду, шифрование.
- Общий буфер обмена: текст между всеми устройствами, картинки между компьютерами с Linux.
- Передача файлов и «Поделиться» на Android.
- Проводник по файлам любого устройства: вкладки, две панели, поиск, закладки, свойства, zip, перетаскивание, копирование между устройствами.
- Просмотр картинок, PDF, офисных документов, кода, Markdown и архивов.
- Сетевые папки; на Linux они монтируются в `~/Перекат/Сеть`.
- Удалённый доступ через свой сервер на VPS с установкой из окна.
- Пульт: мышь между компьютерами, телефон как тачпад, клавиатура и пульт для музыки.
- Уведомления телефона на компьютере, заряд батареи, «найти устройство».
- Свои команды для запуска с других устройств.
- Значок в трее и запуск вместе с системой.
- Интерфейс на русском и английском.

Совместимость с KDE Connect есть, но по умолчанию выключена.
